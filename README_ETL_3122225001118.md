## 🚀 Overview
This project builds a modular ETL pipeline that extracts, transforms, and loads open cybersecurity threat-intelligence feeds into a MongoDB database.

---

## ⚙️ Architecture
**Modules**
| Layer | File | Function |
|--------|------|-----------|
| Extract | `core/extractor.py` | Fetches feeds via HTTP |
| Transform | `core/transformer.py` | Cleans / parses data using pandas |
| Load | `core/loader.py` | Inserts JSON docs into MongoDB |
| Utility | `core/utils.py` | Logging + timestamp management |

**Data Flow**
External Feeds → Extractor → Transformer → Loader → MongoDB (threat_feeds_db)

---

## 🌐 Data Sources
| Feed | Endpoint | Description |
|------|-----------|-------------|
| Botnet C&C IPs | https://feodotracker.abuse.ch/downloads/ipblocklist.csv | Command & Control Servers |
